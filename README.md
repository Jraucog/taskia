## 🎯 La Visión: De la Procrastinación a la Maestría de Alto Rendimiento

La mayoría de las personas fracasan al crear disciplina porque las apps convencionales cometen dos errores fatales:
1. **El castigo binario:** Fallas un día por fuerza mayor y la racha vuelve a 0, detonando el efecto abandono (*"qué más da, ya perdí"*).
2. **La pasividad:** La app solo espera a que marques una casilla, sin darte herramientas vivas para ejecutar en la trinchera del día a día.

**TASKIA invierte el paradigma:** Te trata como a un profesional de élite. Te brinda soporte táctico en tiempo real (respiración para el cortisol, temporizadores de tempo excéntrico para hipertrofia y articulaciones, preguntas de control de metas) y mide tu consistencia con **SLAs rodantes de alta exigencia**.

### 1. 📊 Disciplina Medida bajo SLAs (Service Level Agreements)
- Importa la métrica de disponibilidad de sistemas de misión crítica: mide tu consistencia rodante de los últimos **7 días**.
- Configura tu umbral de exigencia (ej. **85% SLA**).
- Clasificación visual instantánea:
  - 🟢 **Saludable:** Mantienes la consistencia y la inercia positiva.
  - 🔴 **En Riesgo:** Advertencia preventiva antes de que pierdas el hábito.

### 2. 🧬 Bio-Hacking, Fuerza Funcional & Longevidad ("Healthy High-Performance")
- **Entrenador Táctico de Respiración Rítmica en Vivo:**
  - Guía visual con orbe dinámico y animaciones de expansión diafragmática.
  - Protocolos neurobiológicos reales: **Box Breathing 4-4-4-4**, **Suspiro Fisiológico (Andrew Huberman)** para colapsar picos de estrés, y **Método 4-7-8** para activación parasimpática.
  - **Campana tibetana suave con frecuencias armónicas (528 Hz / 432 Hz)** generadas con Web Audio API para entrenar con ojos cerrados.
- **Temporizador Inteligente Inter-Series:**
  - Control de descansos (45s / 60s) con contador en vivo para rutinas de calistenia, TRX, tren inferior y tendón de Aquiles.
  - Foco en tempo y control excéntrico (3-4 segundos de bajada controlada) para hipertrofia funcional y protección articular.
- **Protocolos de Hidratación & Energía Celular:**
  - Registro de vasos y distribución horaria para evitar disrupciones del sueño profundo.

### 3. ✍️ Reprogramación Mental Subconsciente: Reto Brian Tracy (21 Días)
- **Reinicio Estricto Configurable:** Si no cumples la escritura de tus metas un solo día programado, el contador vuelve a 0.
- **Pregunta de Control Diario:** Diálogo reflexivo matutino (*"¿Escribiste hoy tus 10 metas a mano, de memoria y en Fórmula 3P sin mirar el día anterior?"*).
- **Consultor de Metas Oficiales de Referencia:** Acceso instantáneo a tus 10 metas maestras con fecha de entrega y categoría (Físico, Negocios, Música, Hogar).

### 4. 🧭 Vision Board 3P & Asistente Adversarial "Grill Me"
- Conecta tus grandes aspiraciones de vida con la acción diaria.
- **Grill Me Wizard:** Un interrogatorio interactivo en 4 pasos que te obliga a:
  1. Identificar el área de salto cuántico (Salud, Software/Negocios, Música, Entorno).
  2. Redactar en **Fórmula 3P** (*Presente, Positivo, Personal*).
  3. Desnudar el **Por Qué Profundo** (*¿Qué pierdes si NO lo logras?*).
  4. Fijar una **Fecha Límite Innegociable**.

### 5. 🔊 Bucle Dopamínico Sensorial PWA (Neurobiología del Refuerzo)
- **Visual:** Dynamic Island animada y lluvia de confeti balístico.
- **Auditivo:** Acorde ascendente sintetizado (Do5 a Do6) para consolidar la recompensa inmediata tras tareas exigentes.
- **Táctil (Haptic Feedback):** Micro-vibraciones en smartphones compatibles (`[40, 30, 80] ms`) al marcar logros.

### 6. 🥋 Personalización de Estado Mental: 7 Temas de Élite

- **Saiyan Blue Divino (Modo Claro):** Claridad celestial sin tonos oscuros.

## ⚡ Puesta en Marcha Rápida

### 1. Backend (Django REST)
```bash
cd backend
python -m venv venv

# Windows
.\venv\Scripts\activate
# Linux/macOS
source venv/bin/activate

pip install -r requirements.txt
python manage.py migrate
python manage.py seed_data      # Carga programas oficiales, coaches y datos base
python manage.py runserver 0.0.0.0:8000
```
- **API Swagger Viva:** `http://localhost:8000/api/docs/`

### 2. Frontend (React + Vite PWA)
```bash
cd frontend
npm install
npm run dev -- --host 0.0.0.0 --port 5173
```
- **App en Vivo:** `http://localhost:5173/`

### 3. Build de Producción & Auditoría TypeScript
```bash
cd frontend
npm run build
```
